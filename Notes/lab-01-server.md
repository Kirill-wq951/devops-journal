# Лаба 1 — сервер с нуля (15.10.2026)

## Что сделал
Поднял Ubuntu на VPS, создал собственного пользователя `romango` с `sudo`, настроил вход по SSH-ключу, настроил Nginx для отдачи статической страницы и проверил, что сервис переживает перезагрузку. Создал Git-репозиторий для DevOps-журнала.

## Что понял
- `enable` и `start` — разные команды. `start` запускает сервис сейчас, а `enable` настраивает его автоматический запуск при загрузке системы.
- `#` в конфигурационном файле обозначает комментарий. Закомментированная строка с нужным значением не применяется.
- `sshd -T` показывает итоговую конфигурацию SSH-сервера, а поиск через `grep` по файлу помогает увидеть только совпадающие строки в файле.
- Исходящий IP-адрес, например полученный через `ifconfig.me`, и доступность сервера для входящих подключений — разные вещи.

## Грабли, на которые наступил
- Вставил SSH-ключ в командную строку вместо текстового редактора, из-за чего `nano` открыл четыре буфера.
- Создал каталог `~/.ssh` с помощью `sudo`, поэтому владельцем стал `root`. Из-за неправильного владельца SSH не смог корректно использовать ключи.
